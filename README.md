Welcome to the GitHub directory for the project titled "Watching Enzymes Wiggle - Understanding DERA Dynamics"!
In this directory you'll find python scripts to analyse wet lab experiments (under ./wet_lab_analysis), as well
as bash scripts intended to run and analyse molecular dynamics simulations (under ./MD_simulations).
I tried making these scripts self-explanatory by adding comments. In order to run the HREX MD scripts on snellius, 
you will need to download and install a GROMACS version patched with PLUMED, the easiest way is in an apptainer.
Enjoy watching enzymes wiggle!
